编辑器怎么用

  1. 先建关卡空间：顶部填列数 / 行数，点「重建关卡」。建好后就能编辑（重建会先问你一次）。
  2. 画墙体：选「墙体」，在网格上按住左键拖过去就是一整排墙；点已有墙 = 拆掉。墙体工具下右键不会删东西。
  3. 放出生点 / 复活点 / 终点：选好工具后按住左键拖出一个矩形，松手就落成一片区域； 紧挨着的同名区域会自动吸附成一整块。玩家出生在出生区域的正中心， 走进终点区域的任意一格都算到达。出生点和终点全局各只保留一处（画新的会替掉旧的），复活点可以画好多处。
    单击已画好的区域 = 取消那一格。
  4. 放障碍并画巡逻路径：选「圆形障碍」→ 点一个空格子放下障碍（这就是初始位置）， 再点一个格子当巡逻点，障碍就自动保存好，不用一直加点。 想画更复杂的路线：选中它 → 右侧点「添加路径点」（按钮会变成「保存当前路径点」）， 然后按顺序点格子，虚线连起来标出方向；路径点之间可以随便相交（哪怕穿过别的障碍的路径）， 加完点「保存当前路径点」收工。只点一下就点「保存当前路径点」，它就是个原地不动的障碍； 路径格不可点击，删路径点用属性面板里的小 ×。起始点必须放在空格子上 —— 点在墙 / 出生点 / 复活点 / 终点上会选中那个设施；点障碍的起始点（红点）选中障碍，按住起始点拖动可以整体搬家。
  5. 测试游玩：点「▶ 测试游玩」直接在编辑器里玩一把这关（WASD / 方向键移动）， 障碍按你设的方式动，能试出手感；Esc 或再点一下按钮回编辑。
  6. 让障碍转圈（圆周移动）：选中障碍后，把右侧「移动方式」改成圆周旋转， 设一个旋转半径和顺 / 逆时针。圆心只是轨迹锚点（不占格子，放在出生点 / 复活点 / 终点上也行）， 初始位置固定在圆心正右方，点那个圆就能选中、按住拖动搬家； 圆心还可以对齐到格子中心或网格十字交点（右侧「圆心对齐」）。 速度单位仍是像素/秒，半径越小转得越快。
  7. 调参数：选中障碍后右侧能调 速度（10~1000 像素/秒）、往返 / 循环、半径； 路径点后面有小小的 ×，点一下删掉那个点。
  8. 选择 / 删除：切到「选择 / 查看」后，左键点选（墙、出生点、复活点、终点、障碍都能选）， 按住左键拖拽可以框选一片，选中的东西会显示半透明状态，然后右键 = 批量删除。
  9. 改错了别怕：Ctrl+Z 撤回、Ctrl+Y 恢复，也可以用顶部那两个按钮，每一步改动都能退回去。
  10. 预览 / 检查 / 试玩：点「预览运动」（或按空格）让障碍按你设的方式动起来； 点「▶ 测试游玩」自己跑一遍；点「检查能否通关」用时间展开搜索验证这关真能过。
  11. 保存前的校验：只要有出生点、有终点就能保存（复活点不是必须的：没有复活点，被撞后就回出生点）。
  12. 保存去哪：点「保存」存进本机浏览器（游戏里会以「自制关卡」出现，单人和本地多人都能玩）； 也能「导出为 .json」把关卡发给别人；想内置到游戏里，就把导出的 JSON 替换 games/dodge/shared/levels.json 里的一项。
