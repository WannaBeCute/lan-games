编辑器怎么用

  1. 先建关卡空间：在顶部填列数/行数，点「重建关卡」。建好后就能编辑了（重建会清空内容）。
  2. 放元素：左侧选工具，然后在网格上点。墙、出生点、复活点、终点都是点一下放、再点取消。
  3. 放障碍并画巡逻路径：选「圆形障碍」→ 点一个空格子放下障碍，此时自动进入路径编辑； 接着按顺序点你想让它经过的格子，路径点之间会用虚线连起来并标出方向。 点路径上的小圆点可以删掉那个点；右键点障碍可以删掉整个障碍。
  4. 调参数：选中障碍后，右侧能调速度（20~300 像素/秒）、往返/循环、半径。
  5. 预览：点顶部「预览路径」让障碍按路径动起来，再点一下停止。
  6. 保存前的校验：至少要有一个出生点和一个复活点，否则不能保存； 出生点/复活点/终点压在墙上、和障碍巡逻点重合等问题会直接列在下方面板里。
  7. 保存去哪：点「保存」存进本机浏览器（游戏里会以「自制关卡」出现，可以单人和本地多人玩）， 也可以用「关卡库 → 导出为 .json 文件」把关卡发给别人； 想内置到游戏里，就把导出的 JSON 交给管理员，替换 games/dodge/shared/levels.json。
