# 机房小游戏 · 联机小游戏合集

可以在机房局域网里直接跑起来的小游戏合集（坦克大战、五子棋、你画我猜）。
**方块躲避**还在打磨，暂时**不上主页**，但服务端照常装配 —— 想进去直接在地址栏敲 `/dodge/`
（关卡编辑器是 `/dodge/editor.html`），给开发者留门。
**服务端零 npm 依赖**（WebSocket 协议用 Node 内置模块自己实现），
任何一台装了 Node.js 的 Win 电脑双击 `start.bat` 即可开服，其他电脑用浏览器打开地址就能玩。

平台层与游戏层是分开的：**想再加一个游戏，只需要在 `games/` 下新建一个文件夹** ——
服务端会自己发现、自己挂载，主页也会自动多出一张卡片，`platform/` 一行都不用改
（约定与模板见 [`games/README.md`](games/README.md)，里面有段可直接发给同学或 AI 的提示词）。

```
双击 start.bat  →  控制台会打印局域网地址（如 http://192.168.1.5:8080）
同学浏览器输入该地址  →  主页选游戏  →  开玩
```

> 想拿源码、或者想一起开发？仓库在 GitHub（公开）。克隆地址、加游戏的步骤、协作流程与自检清单
> 见文末 **10. 获取代码 · 一起开发**。

## 1. 运行环境

| 项目 | 要求 |
| --- | --- |
| 服务器 | 任意一台 Win 电脑，安装 [Node.js](https://nodejs.org)（**建议 18+，最低 14**） |
| 客户端 | Chrome / Edge 等现代浏览器，无需安装任何东西 |
| 网络 | 所有电脑在同一局域网；**不需要外网** |
| 依赖 | **0 个 npm 包**，不需要 `npm install` |

启动方式二选一：

```bat
:: 方式一：双击（推荐，中文名更好找）
启动游戏.bat
:: 或者
start.bat

:: 方式二：命令行
node platform/server/server.cjs                     :: 默认 8080 端口
node platform/server/server.cjs --port 9000
```

> **请勿直接双击 `platform\server\server.js`。** 那个文件不是入口，只是防误点提示；
> 双击 `.js` 会被 Windows 自带的脚本宿主（JScript）打开，弹出 `语法错误 800A03EA`。
> 正确的入口是 `platform\server\server.cjs`。
>
> 首次运行若 Windows 弹出防火墙提示，请选择「允许访问」，否则其他电脑连不上。
> 若是机房统一管理，可让管理员放行该端口，或用 `--port` 换一个已放行的端口。

## 1.1 让别的电脑访问（联机步骤）

**第 1 步 · 在服务器那台电脑上启动**（双击 `启动游戏.bat`）。窗口里会打印出要分享的地址，例如：

```
  【本机打开】  http://localhost:8080

  【让别的电脑访问下面这个地址】
      http://10.10.243.136:8080         (以太网)
```

同时在浏览器打开 `http://localhost:8080`，主页上会出现一条绿色的
**「让别的电脑访问下面这个地址」** 提示条，点「复制地址」就能直接发给同学。

**第 2 步 · 其他电脑**：连上同一个机房网络（同一网段），
用 Chrome / Edge 打开那个地址就行 —— **不需要安装任何东西**。打开后进主页 → 选游戏 → 联机。

**第 3 步 · 在对局里碰头**

| 游戏 | 怎么找到对方 |
| --- | --- |
| 坦克大战 | 房主点「新建房间」，把 **4 位房间号**告诉同学；同学点「加入房间」输入房间号 |
| 五子棋 | 各自页面上的 **邀请码** 给对方，或输入对方的邀请码点「发起邀请」，对方接受即开局 |
| 你画我猜 | 房主点「新建房间」，把 **房间号**告诉同学；或在「好友」里直接对好友点「邀请组队」 |
| 方块躲避 | 房主点「新建房间」，把 **4 位房间号**告诉同学；或在「好友」里直接对好友点「邀请组队」 |

> 好友列表里，**正在房间里的人会标一个「组队中」**，这时他的「邀请组队」按钮是灰的 ——
> 别把人从别人的局里拉走。反过来，你自己已经在别人的房间里时去点别人的组队邀请，
> 也只会得到一句「你已在组队状态中，无法接受邀请」，不会把你从当前这局拽出去。

### 打不开怎么排查（按顺序）

| 现象 | 原因与处理 |
| --- | --- |
| 同学浏览器显示「无法访问此网站」 | ① 两台电脑是否在同一网段；② 地址是否用了**局域网地址**而不是 `localhost`；③ 见下一行防火墙 |
| 地址没错但仍然连不上 | **Windows 防火墙拦了入站端口**。右键 `开放防火墙端口.bat` → **以管理员身份运行**（换端口就带上参数，如 `开放防火墙端口.bat 9000`）。撤销：`netsh advfirewall firewall delete rule name="机房小游戏 8080"` |
| 服务器窗口被关了 | 服务就停了。窗口需要一直开着，关窗口 / Ctrl+C 即停止服务 |
| 电脑有多个 IP，不知道用哪个 | 以窗口里打印的为准（已自动过滤 VMware / WSL 等虚拟网卡），和主页绿色提示条里的是同一个 |

## 2. 坦克大战

### 2.1 玩法

- 坦克**只用键盘**控制，完全不需要鼠标。坦克可以 **360° 连续旋转**，炮弹沿车头方向飞出：

  | 按键 | 作用 |
  | --- | --- |
  | **↑** | 前进（沿车头方向，可以是任意角度） |
  | **↓** | 后退 |
  | **←** | 左转（逆时针，约 240°/秒） |
  | **→** | 右转（顺时针，约 240°/秒） |
  | 开火键 | 发射，只有一个键 |

- **子弹上限 5 发**：同屏属于你的子弹最多 5 颗，打完再补，必须控制节奏。
- **子弹会撞墙反弹**：打到墙上按入射角反射（竖直面翻 X、水平面翻 Y、犄角原路弹回），
  一枚子弹最多反弹 8 次。
- **子弹飞一段时间会自己消失**：每发子弹存活 **3.4 秒**，到点自动消失，不会一直乱飞。
- **子弹会打中自己**：射出炮口后它就不再认主人了 —— 在墙角开枪很容易被弹回来的子弹打死，
  **贴墙乱开枪是很危险的**。（自己被自己打死会计一次死亡，但不会给任何人加击杀。）
- 地图只是**「看起来像迷宫」**：在空场地上随机画大量走向随机的墙段（途中还会拐弯）+ 随机 2×2 方块，
  形成**多岔路、多死胡同**的曲折布局 —— 每次都不一样，**不是规则迷宫**（没有房间网格那套结构）。
  内部墙体占比稳定在 **24%~36%**（墙面足够多，比早期版本密得多），
  可活动空地仍保证 **≥ 全图 1/3**（实测 52%~62%）。
- **出生点是随机的**：从开阔空地中随机选取，再用「最远点采样」把几辆坦克彼此拉开
  （实测最小间距 **≥ 8 格 ≈ 256px**），避免一开局就贴脸；出生点周围会留出一小片空地，
  车头自动朝向地图中心。
- 墙体材质：约 **42% 是钢墙**（不可摧毁，反弹很硬）、**58% 是砖墙**（可以打穿）。
- 对局进行一段时间后开始**随机掉落特殊武器**，场地上最多同时存在 3 个（侧栏只显示图标，鼠标悬停看中文说明）：

  | 图标 | 名称 | 效果 |
  | --- | --- | --- |
  | ⚡ | 加速 | 移动速度 +45%，持续 18 秒 |
  | 🔥 | 连发 | 开火间隔缩短 58%，持续 18 秒 |
  | 🔱 | 三连发 | 一次射出 3 颗平行子弹，持续 18 秒 |
  | 🎯 | 穿甲弹 | 可击毁钢墙，子弹更快，持续 18 秒 |
  | 🔫 | 激光 | **下一次开火变成贯穿光束**，扫平沿途砖墙、钢墙**和草丛**，**只能用一次** |
  | 🛡 | 护盾 | **只挡 1 颗子弹**（挡完即失效），持续 14 秒 |
  | ❤️ | 加命 | 命数 +1（**最多 5 条**，满了就不再加） |
  | 👻 | 隐身 | **20 秒**隐形；**开火或捡到其他道具会立刻现形** |

  > **隐身只在联机模式掉落。** 单机和本地双人对战时对手就在同一块屏幕上（AI 也是直接读战场数据找目标），
  > 隐身没有意义，所以本地对局的道具池是 7 种、联机是 8 种。

- 场地上还有树丛（能藏住坦克）等元素，图形为纯几何图形组合，无贴图、无 3D、无光影。
  - **草丛变大了**：一丛草会盖住整格（连坦克一起遮住），但圆形叶团之间留着缝隙，看得出是一丛丛的草。
  - **草丛是"正常遮挡"**：草画在坦克上面，钻进去就被草盖住 —— 不是把人变没。
    躲进草丛时**不显示头顶名字**（名字会浮在草上方暴露位置）；**你自己**的车会另外半透明补画一层，
    免得连自己也看不见。草丛不挡子弹，子弹照常穿过去。
  - **子弹会把草打薄**：子弹每穿过一格草丛就削掉一档 —— 完整草丛 → **稀疏草丛**（又小又稀，**藏不住人**）→ 空地。
  - **激光是"大幅"清草**：激光扫过的草丛，正面那格直接烧成空地，周围一圈也一起被打薄/烧掉。
- **每局生命数可改**：房主在联机房间里可设 1~5 条（默认 1 条）；单机 / 本地双人也在开局面板里可选。
- **场上掉哪些道具，房主说了算**：联机房间里列出 8 种道具，**默认全选**，点一下即可取消/勾回
  （至少保留一种）。单机与本地双人不会掉「隐身」——同一块屏幕上看不见对手没有意义。
- **子弹不伤害自己（默认开启该保护）**：房间里有一开关「子弹会伤到自己」，默认**关闭**，
  也就是反弹回来的子弹不会再把自己打死；想恢复"会被自己打中"的硬核玩法就把它打开。
- **掉落节奏**：不再纯随机，而是「洗牌袋」——一轮之内 8 种各掉一次、顺序随机，
  刷新间隔 4~7 秒，约 40 秒就能把 8 种见一遍，不会再出现"玩一局连激光都没见到"。

### 2.2 三种模式

| 模式 | 说明 |
| --- | --- |
| **单人游戏** | 三档难度（简单 / 普通 / 困难）。AI 会持续增援，你只有 3 条命，比拼击杀数，成绩存本机。 |
| **多人游戏** | 同一台电脑双人对战。P1 用方向键，P2 用 `W A S D`。**局数制**，打完结算排名。 |
| **在线联机游戏** | **4 位房间号，支持 2~4 人**。房主新建房间 → 同学点「加入房间」输入房间号即可进入。 |

### 2.3 联机房间：准备制 + AI 开关

进入房间后，玩家列表里会实时显示每个人的状态：

| 玩家 | 显示 |
| --- | --- |
| 房主 | `房主 · 已就绪`（房主不需要点准备，他负责点开始） |
| 其他玩家 | `未准备` / `✔ 已准备`，各自有「我已准备好」按钮，可随时取消 |

- **只有所有人都准备了，房主的「开始游戏」按钮才会亮起**。
  条件不满足时按钮是灰的，并且**旁边会直接写出原因**，例如：
  「还有 1 人未准备：小明」「只有你 1 人：请打开「AI 坦克」开关，或等其他人加入」。
  能开始时显示绿色的「全员就绪，可以开始（共 2 人）」。
- **AI 坦克是可选开关，而且默认关闭**：房主可以在房间里打开「补充 AI 坦克」。
  - **关**（默认）：完全不加入任何 AI；此时如果房间里只有 1 个人，开始按钮会禁用并写明原因。
  - **开**：真人不足 2 人时自动补 1 辆 AI，一个人也能开局试玩。
  - 2 人及以上的真人对局，本来就不会加入任何 AI。
- 开赛时准备状态会自动清空，下一届回到大厅需要重新准备。
- **对局进行中有人退出，整场直接结束**：其余玩家会收到提示并回到主页，房间同时回收
  （不做"少一个人继续打"）。

### 2.4 局数与排名（房主可设）

- 房主在大厅设置 **对局局数**：**默认 20 局，最多 999 局**（1~999 之间任意值）。
- 每局重新随机地图；每局最后存活的坦克记 **1 胜**，击毁一辆坦克记 1 杀。
- **决出胜负后先等 2 秒再结算**：让最后一击的爆炸、碎片动画播完；
  这 2 秒里如果剩下的人也被打掉（同归于尽），本局就判 **平局（流局）**，双方都不记胜场。
- **胜利画面**：每局结束会在**正中间画出获胜的那辆坦克 + 玩家名**（同色的涂装、写着「本局胜者」），
  下面才是排名；并列流局则显示「平局」。
- **全部局数打完的结算界面**：中间是**总冠军**（画出坦克 + 名字 + 胜场/击杀），
  下面单独一行 **🎯 击杀榜第一**（击杀最多者，并列看死亡少），最后才是完整战绩排名。
- 单局时限 180 秒，超时按击杀数排名。
- **全部局数打完后结算总排名**：先比胜场 → 再比击杀 → 死亡少者靠前。
- 人数不足 2 人时，系统会自动补 AI 坦克，单人也能跑完所有局数。
- 其他操作：局间有结算面板与倒计时；对局中房主可随时在房内改颜色/涂装；打完可「回到大厅再来一局」。

### 2.5 房间内的自定义

进入房间后可以设置：

- **颜色**：8 种（蓝 / 红 / 绿 / 黄 / 紫 / 青 / 橙 / 白）
- **涂装**：4 种（经典 / 条纹 / 迷彩 / 霓虹）
- **键位**：上、下、左、右、开火共 5 个键，点按键框后按下新键即可改（Esc 取消），会做重复键校验

## 3. 五子棋

### 3.1 玩法

- 15×15 棋盘，传统规则：横、竖、斜任意方向**先连成五子或以上者获胜**。
- **每人只有一次悔棋机会，悔棋不需要对方同意**，点一下立即生效：
  - 只要**自己刚落下的那一手对方还没有应手**，就能直接撤回它，机会随即用掉；
  - 如果对方已经应手，这一手就不能再悔了 —— 机会**不会消耗**，等自己下一次落子后（对方还没应手时）再用；
  - 悔棋只撤回**最后落下的那一手**，撤回后轮次回到自己。
  - 单人对战电脑时同理，点「悔棋」撤回自己最近一手（连同电脑紧跟的应手），轮次回到你。
- **落子预览**：鼠标（或手指）在棋盘上选择落子位置时，会显示一颗半透明的预览棋子，颜色就是**当前该落子一方**的棋子颜色（黑方回合显黑子、白方回合显白子）；同一时刻**对方也能看到你在考虑的位置**（淡棋子 + 虚线圈）。
- 支持认输、重新开始、显示手数、显示坐标。

### 3.2 单人游戏

三档难度：简单（带随机性）/ 普通（会攻会守）/ 困难（额外做一步前瞻）。AI 基于棋型窗口评分，攻守兼备。

### 3.3 联机（邀请制）

- 每个人打开联机页都会看到一个 **本机专属邀请码**（由 IP 派生，6 位易读字符，同名机房内唯一；同一 IP 多开也会自动区分）。
- 想和谁下棋，就把自己的邀请码给他，或**输入对方的邀请码**点「发起邀请」。
- 对方会收到弹窗，**接受**后立即开局。
- **黑白轮换**：同一对玩家每再开一局，执黑/执白就互换一次（上一局执黑的这局执白），
  不会永远是同一个人先手。
- 对局结束后可以「邀他再来一局」（复用同一个邀请码）。

### 3.4 视觉风格

整页为**传统木质棋盘**风格：浅木色棋盘（#DEB887）配深棕线条与星位，棋子是纯黑与米白的圆形棋子，
最后一手用红点标记，连成五子画一条朴素的红棕细线。界面字体使用楷体 / 宋体等衬线字体，
按钮为木色圆角矩形，没有渐变发光、玻璃拟态、霓虹、粒子或 3D 效果，像把实体棋盘放在木桌上。

## 4. 方块躲避（The World's Hardest Game 风格）

方格玩家 + 圆形巡逻障碍，碰一下就死，靠**卡时机穿过缝隙**。**自带关卡编辑器**，可以自己做关。

### 4.1 玩法

- 关卡建在网格上（每格 40×40），玩家是 36×36 的**方格**，障碍是半径 18 的**圆形**：
  沿网格路径来回巡逻，也可以设成**绕圆心转圈**（圆周旋转，半径自定，速度最高 1000 px/s）。
- 操作：**WASD** 或**方向键**（八方向，斜着走不会更快），撞到圆形障碍即死亡。
  `R` 重来本关，`Esc` 暂停。
- 场地是**白底**：**绿**色是出生点和终点，**黄**色是复活点。它们都是**一片区域**（可以有好几格，
  紧挨着的同色格子自动连成一整块），玩家出生在出生区域的**正中心**，走进终点区域的**任意一格**都算到达。
- 死亡后回到**自己最近踩过的复活点区域**（一个都没踩过就回出生区域中心），复活有 0.5 秒无敌。

### 4.2 ★ 缝隙判定（这游戏难就难在这儿）

> 玩家是有体积的方块，**别想从两个相邻的圆形障碍中间挤过去**。

- 两个相邻格子的障碍圆心相距 40px，两个圆之间的空隙只有 **4px**，远小于玩家 36px 的边长 → 挤不过去。
- 隔一格（圆心 80px）时中间留出 44px 的通道 → 可以穿过去。
- 这条规则不是特判出来的，而是「**点到矩形最近点**」这个标准碰撞算法的自然结果；
  自检里有两组对照用例专门盯着它（`tools/dodgetest.js` 的「缝隙判定」）。

### 4.3 三种模式

| 模式 | 说明 |
| --- | --- |
| **单人闯关** | 10 个关卡从易到难，通关一关解锁下一关，记录每关最好成绩（死亡次数 / 用时） |
| **本地多人** | 同一台电脑 2~4 人同屏：P1 `WASD`+空格、P2 `方向键`+回车、P3 `IJKL`+U、P4 `小键盘8456`+小键盘0 |
| **在线联机** | **4 位房间号，2~4 人**，房主选关、全员准备后开始 |

### 4.4 组队规则（本地多人 / 在线联机）

- **全员到达终点才算通关**：只要有一个人没到，本关就不结束。
- **接应传送**：已经到达终点的队友按「接应键」（联机是空格），把还在跑的队友**直接送到终点**，
  传送有 0.5 秒飞行动画、冷却 3 秒，屏幕会提示「XX 正在接应队友！」。
- 死亡各自独立，回到各自的复活点，不影响别人。
- 联机采用**服务端权威模拟**（60Hz 推进、20Hz 快照），自己的方块做本地预测，所以「按下就动」；
  谁被撞死、谁到了终点一律以服务端判定为准。

### 4.5 关卡数据（可以自己替换 / 自己加）

关卡是一个纯 JSON 文件：**`games/dodge/shared/levels.json`**（页面上通过 `/dodge/shared/levels.json` 读取）。

```json
{
  "version": 1,
  "pack": "方块躲避 · 内置关卡",
  "levels": [
    {
      "version": 1, "id": 1, "name": "初次尝试", "difficulty": 1,
      "cols": 20, "rows": 15,
      "spawns": [{ "col": 1, "row": 7 }],
      "checkpoints": [{ "col": 2, "row": 7 }],
      "goals": [{ "col": 18, "row": 7 }],
      "walls": [{ "col": 0, "row": 0 }, "…"],
      "obstacles": [
        { "id": "obstacle_1", "path": [{ "col": 10, "row": 3 }, { "col": 10, "row": 11 }],
          "speed": 80, "loopMode": "pingpong", "radius": 18 }
      ]
    }
  ]
}
```

- `spawns` / `checkpoints` / `goals` 都是**格子列表**，但语义是**一片区域**：
  四方向相邻的格子会被自动认成同一块（所以 2×2 的出生点就是 4 个格子）。
  出生取区域正中心，终点只要踩到区域里**任意一格**就算到达；出生点和终点各一处（编辑器会保证），复活点可以有很多处。
- `path` 是障碍依次经过的**网格坐标**；`speed` 像素/秒（10~1000）；`loopMode` 为 `pingpong`（往返）或 `loop`（循环）；
  `radius` 默认 18（不超过 18，否则会堵死通道）。
- 想让障碍**原地转圈**：给它加 `orbit`（第一个路径点就当成圆心），就不用管 `loopMode` 了：

  ```json
  { "id": "o1", "path": [{ "col": 10, "row": 7 }], "speed": 200, "radius": 18,
    "orbit": { "radius": 100, "cw": true } }
  ```

  半径 100px、速度 200px/s → 角速度 = v ÷ r = 2 rad/s（**半径越小转得越快**），`cw: false` 表示逆时针。
- 直接编辑这个文件、或换成你自己的一套关卡都行；**服务端和浏览器读的是同一份**，
  改完重启服务端（联机部分）刷新页面即可。
- 也可以把编辑器导出的单个关卡 JSON 追加进 `levels` 数组，做成内置关卡。

### 4.6 关卡编辑器

顶栏「🛠 关卡编辑器」或主页卡片进入 `/dodge/editor.html`（独立页面，和游戏分开）：

1. **先建关卡空间**：填列数 × 行数 → 点「重建关卡」（重建会清空内容，会先问一次）。
2. **画墙体**：选「墙体」，在网格上**按住左键拖过去**就是一整排墙；点已有墙 = 拆掉
   （按住左键从墙上开始拖 = 连着拆）。墙体工具下**右键不删东西**，避免误删。
3. **画出生点 / 复活点 / 终点**：选好工具后**按住左键拖出一个矩形**，松手落成一片区域；
   紧挨着的同名区域会**自动吸附成一整块**。单击已画好的区域 = 取消那一格。
   出生点、终点全局各只保留一处（画新的会替掉旧的），复活点可以画好多处。
4. **圆形障碍与巡逻路径**：选「圆形障碍」→ 点空格子放下障碍（这就是**初始位置**），
   **再点一个格子当巡逻点，障碍就自动保存好**，不用一直加点。想画更复杂的路线：选中它 →
   右侧点「**添加路径点**」（按钮会变成「**保存当前路径点**」），然后按顺序点格子加路径点。
   **路径可以随便相交**（穿过别的障碍的路径也行），路径格不可点击；删路径点用属性面板里的小 **×**。
   起始点必须放在空格子上（点在墙 / 出生点 / 复活点 / 终点上会选中那个设施）；
   **点障碍的起始点（红点）选中障碍，按住起始点拖动可以整体搬家**，只要起始点不重复即可。
5. **让障碍转圈**：右侧「移动方式」改成**圆周旋转**，设旋转半径和顺 / 逆时针。
   **圆心只是轨迹锚点，不占格子**——可以放在出生点 / 复活点 / 终点或任何地方；
   **初始位置固定在圆心正右方**，点那个圆就能选中、按住拖动搬家；
   圆心还能对齐到**格子中心**或**网格十字交点**（「圆心对齐」）。速度是圈上的线速度，半径越小转得越快。
6. **属性面板**：选中障碍后可调**速度**（10~1000 px/s，数值外壳可以直接点进去输精确值）、**往返 / 循环**、**球半径**；
   路径点后面有个小小的 **×**，点一下删掉那个点。
7. **选择 / 删除**：切到「选择 / 查看」后，左键点选（墙、出生点、复活点、终点、障碍都能选），
   **按住左键拖拽可以框选一片**，选中的东西显示半透明状态，然后**右键 = 批量删除**。
8. **改错了别怕**：**Ctrl+Z 撤回**、**Ctrl+Y 恢复**（也可以用顶部两个按钮），每一步改动都能退回去；
   有未保存改动时点「返回主页 / 去玩游戏」会先弹窗问你要不要保存，直接关网页浏览器也会拦一下。
9. **预览 / 检查 / 试玩**：点「预览运动」（或按**空格**）让障碍动起来；点「**▶ 测试游玩**」直接在编辑器里
   玩一把这关（WASD / 方向键控制，Esc 退出）；点「检查能否通关」用时间展开搜索验证这关真能过。
10. **校验**：只要**有出生点、有终点**就能保存（复活点可选：没有的话被撞后就回出生点）；
    压在墙上、和障碍巡逻点重合等问题会直接列出来。
11. **保存去哪**：点「保存」存进本机浏览器（游戏里会作为「自制关卡」出现，可单人和本地多人玩）；
    「关卡库 → 导出为 .json」可以把关卡发给别人，或交给管理员替换 `levels.json` 做成内置关卡。

> 自制关卡目前只支持单人 / 本地多人；在线联机玩的是服务端的内置关卡。

## 5. 底力练习器（音游底力练习）

> 入口：**`/dili/`** —— 这个游戏暂时**不上主页**（`Hub.hidden = true`），
> 只能输网址进（给还没做完/不想上首页的游戏留的门）。
> 玩法照搬开源项目 [EatKano / eatcat](https://github.com/UlyssesZh/eatcat)（MIT）。

### 5.1 玩法（两种模式）

| 模式 | 谱面怎么走 | 什么时候结束 | 排行榜看什么 |
| --- | --- | --- | --- |
| **限时** | 打进哪一行，谱面就上移一格（点对才落格） | 时间到，或点错键 | 打中的行数（分数） |
| **无尽** | 音符**自己往下落**，越落越快（钢琴块） | 有音符落到判定线以下还没打掉 | **最终速度（键/秒）** |

> 无尽模式的速度从 2.0 键/秒起步，每过一行乘 1.015 再加 0.02，上限 26 键/秒 ——
> 你能顶到多快，成绩就是多少。结算里同时给出坚持时间、行数、折合 BPM。

### 5.2 键位（默认）

| 键数 | 默认键位 |
| --- | --- |
| 4K | **D F J K** |
| 5K | **D F 空格 J K**（中间那颗是空格） |
| 6K | **S D F J K L** |

主页会实时显示当前键数的键位；开局界面上也把这一局要按的键摆出来。
要改键位：右上角 **⚙ 设置 → 键位 → 底力练习器**，里面按 4K / 5K / 6K 三列分开配（平台通用键位表）。

### 5.3 布局调整（游戏前）

菜单里的「布局调整」可以调：**游戏区宽度**（占页面比例）、**音符块高度**（100% = 正方形）、
**判定线位置**（把判定区从底边往上抬）、以及**是否显示键位字母**。调完存在本机浏览器里。

### 5.4 皮肤工坊与皮肤广场

一套皮肤可以自定义这些（**都可以留空 = 用默认**）：

| 项 | 默认 |
| --- | --- |
| 背景图片 | 无（空白） |
| 键背景 | 无（空白） |
| 音符图片 | 黑色方块 |
| 音符被击中后图片 | 黑色方块，**透明度默认 50%**（可调） |
| 击中音效 | 内置合成音（短促滴声） |
| 击中错误音效 | 内置合成音（低鸣） |

- 图片用透明背景 PNG 效果最好，但**普通图片也能用**（按原样铺满格子）。
- 单个素材 ≤ 900KB、整套皮肤 ≤ 3MB；超了客户端直接拦下。
- **保存并使用** → 存本机；**上传到皮肤广场** → 存服务器 `games/dili/server/data/skins/`，
  别人在菜单侧栏的「皮肤广场」里点一下就换上（列表最多留 200 套，超出删最旧的）。

### 5.5 排行榜

- 限时模式只有 **20 秒 / 1 分钟 / 3 分钟**三个预选档上传榜单；**自定义时长不上榜**（本地玩）。
- 无尽模式按 **4K / 5K / 6K** 各一张榜，名次看最终速度。
- **每人每榜只留最优记录**（按 IP 认人，破纪录才替换，记录里带着"创造时间"）。
- 可以**点赞**（一人一票、不能赞自己）；48 小时内排名上升显示 ▲、下降显示 ▼。
- 菜单侧栏**实时刷新**（连上就拉、每局结束拉、每 6 秒拉一次）。

### 5.6 数据落盘

```
games/dili/server/data/
├─ boards.json              排行榜（每 500ms 合并写一次，进程退出时补写，不掉榜）
└─ skins/<id>.json          皮肤广场（素材以 data URI 内联，整体自包含）
```

> 单人游戏：**没有房间、没有邀请**，`Hub.busy()` 恒为 `null`，所以好友列表里永远不会显示「组队中」。

## 6. 设置（主页右上角「设置」）

- **昵称**：可以直接改，**改完立刻同步**到联机房间/棋盘（不用重进房间、不用刷新页面）。
- **总体 UI 主题（深色 / 浅色）**：点一下**即时生效**，存在本机。
  深色是默认；浅色适合白天或投影。它只换一套 CSS 变量、不动布局，
  游戏自己的主题（方块躲避的「纸上关卡」）声明更靠后、优先级更高，所以在它自己的页面上不受影响。
  聊天控件、私聊小窗、聊天气泡都跟着这个设置走 —— 见下一节。
- **音效音量**：0~100% 滑块 + 静音开关 + 试听。音效全部用 WebAudio 现场合成，**没有任何音频文件**。
- **键位设置**：顶部是**游戏预选列表（坦克大战 / 五子棋 / 方块躲避）**，点谁改谁的键位——
  坦克大战是玩家 1 / 玩家 2 各 5 个键（前进 / 后退 / 左转 / 右转 / 开火）；方块躲避是玩家 1~4
  各一套（上 / 下 / 左 / 右 / 接应，玩家 1 默认方向键 + 空格接应）；五子棋只用鼠标，没有键位可设。
  点一下按键框再按新键即可修改，同一玩家内重复键会提示。
- **底层安全区**：方块躲避里玩家站在出生点 / 复活点 / 终点范围内（含边界线）时**永远不会因障碍死亡**，
  所以障碍轨迹压着设施也只是提醒、不拦保存。
- 昵称同时用于单机记分与联机房间/棋盘显示；改完点保存即时生效。
- 设置保存在浏览器 localStorage，换电脑需要重新设置。

## 7. 好友系统（所有游戏通用）

好友列表、聊天、组队邀请都在**平台层**实现，主页、坦克、五子棋（以及以后新增的任何游戏）共用同一份数据。
顶栏点 **「👥 好友」** 即可打开。

### 5.1 怎么用

| 步骤 | 操作 |
| --- | --- |
| 加好友 | 「好友」→ **在线人员**（列出所有在线的人与**完整 IP**）→ 点「加好友」 |
| 收邀请 | 对方电脑**左下角**弹出邀请卡（贴着边、窄条，不遮挡游戏画面），点「接受」即成为好友 |
| 聊天 | 「我的好友」→ 点「聊天」，左下角弹出聊天小窗，回车发送；对方在线即时送达，不在线则存入记录 |
| 组队 | 「我的好友」→ 点「邀请组队」，对方左下角弹出邀请，点「接受」**直接进入对局/房间，不用再报邀请码** |

- 坦克：在房间大厅点「邀请好友」，或对好友点「邀请组队」→ 对方接受后自动跳转并加入你的房间。
- 五子棋：联机页点「邀请好友（免邀请码）」，或对好友点「邀请组队」→ 对方接受后自动发起对局。

### 5.2 身份与数据

- 好友以**电脑（IP）**为单位：同一台电脑重开页面、换游戏、换房间，好友都不会丢；
  对方改昵称会实时同步（改名后好友列表自动更新）。
- 好友关系与聊天记录**服务端重启后也还在**（落在 `platform/server/friends-data.json`，已加入 `.gitignore`）。
- 群聊/广播没有做：只能和好友一对一聊；非好友不能聊天、不能组队邀请。
- 消息与昵称都按纯文本转义，不会被当成 HTML 执行。

### 5.3 消息协议（`friends.*`，平台层直管）

| 方向 | 类型 | 说明 |
| --- | --- | --- |
| C→S | `friends.add` / `accept` / `reject` / `remove` | 加好友 / 接受 / 拒绝 / 删除 |
| C→S | `friends.chat` / `friends.history` | 发消息（带 mid 用于回显去重）/ 拉历史 |
| C→S | `friends.team` / `friends.teamReply` | 组队邀请与应答 |
| C→S | `friends.refresh` | 拉一次全量状态（打开好友面板时用） |
| S→C | `friends.state` | 全量状态：在线人员、好友、收到的邀请 |
| S→C | `friends.invited` / `friends.result` | 左下角邀请弹窗 / 操作结果 |
| S→C | `friends.presence` / `friends.chat` | 上下线（含改名）/ 聊天消息 |
| S→C | `friends.teamInvited` / `friends.teamResult` | 组队邀请与应答结果 |

### 5.4 给新游戏的接入方式（可选）

见 [`games/README.md`](games/README.md) 的「接入好友系统」：两行引入 + 一次
`WB.Friends.registerGame({...})` 登记组队能力，平台层代码一行不用改。

## 8. 聊天控件（所有页面通用）

左下角一直有个聊天控件（`platform/web/shared/chat.js` + `chat.css`，主页 / 三个游戏页 / 关卡编辑器都有）：

- **默认是收纳状态**：就一条，显示**最新一条消息**（谁说的 + 内容）+ 未读角标，
  **同时**列出好友（在线优先、未读优先，点谁就跟谁开启私聊）—— 收起时"看消息"和"找人"两件事都能干；
- **按住标题栏可以拖到任意地方**（位置记在本机），点一下控件就展开，点「–」收起，点「×」隐藏成小圆钮；
- **位置 / 收纳 / 展开这些状态刷新页面也不会被重置**（控件的"常驻"承诺）；
- 展开后两个页签：
  - **「本局」**：**房间频道聊天，房间里所有人可见**。建房 / 加入房间 / 开局时就自动建好频道
    （`WB.Chat.enterRoom({ game, code, title })`），刷新页面回到同一房间会自动接回来；
  - **「好友」**：好友列表，点一个好友 → 弹出**独立的私聊小窗**（含历史记录、未读、在线状态）。
    **换页面时小窗会跟着过去，不会自动被刷掉**；只有**手动刷新网页**（F5 / Ctrl+R）才会清空。

> **配色：固定深色，不跟页面主题走。**
> 控件根节点、私聊小窗、左下角邀请弹窗都挂着 `.wb-dark` 作用域（见 `app.css`），
> 所以哪怕页面本身是亮色的（方块躲避的「纸上关卡」、你画我猜的整页亮色），
> 聊天控件、小窗和气泡依然是深色 —— 之前这里跟着页面变浅，气泡底色和文字只差几个色阶，
> 糊成一片看不清。想整体用浅色，走 **设置 → 外观 → 总体 UI 主题 → 浅色**（那时浮层一起变浅）。

两块能力在服务端的边界很清楚（`platform/` 里不认识任何游戏）：

| 层 | 文件 | 生命周期 | 用途 |
| --- | --- | --- | --- |
| 好友私聊 | `platform/server/friends.cjs` | **落盘**（`friends-data.json`），跨游戏跨页面都在 | 好友之间的 1 对 1 聊天、历史记录 |
| 房间频道 | `platform/server/chat.cjs` | **内存**，房间没人了就回收 | 一局里所有人可见的公共聊天 |

房间频道消息（`chat.*`）：

| 方向 | 类型 | 说明 |
| --- | --- | --- |
| C→S | `chat.join` | `{ channel, title }` 进频道，`channel` 形如 `dodge:1234`（服务端只校验格式） |
| C→S | `chat.leave` | `{ channel }` 离开（不带 channel 表示退掉全部） |
| C→S | `chat.send` | `{ channel, text, mid }` 发言，广播给频道内所有人 |
| S→C | `chat.log` / `chat.msg` / `chat.members` / `chat.system` / `chat.error` | 进频道回放、消息、成员表、进出提示、错误 |

游戏侧只要在房间生命周期里调两行（见 `games/*/client/main.js`）：

```js
WB.Chat.enterRoom({ game: 'dodge', code: room.code, title: '方块躲避 · 房间 ' + room.code });
WB.Chat.leaveRoom();          // 退出房间 / 对局结束时
```

### 为什么要分 platform / games

**平台层（`platform/`）**：只做「跑游戏」这件事 —— 静态资源、WebSocket、客户端注册、主循环，
**一行游戏规则都没有**。

**游戏层（`games/<名字>/`）**：每个游戏完全自包含，各占一个文件夹：

| 位置 | 作用 |
| --- | --- |
| `games/<名>/client/` | 该游戏的网页（HTML/CSS/JS） |
| `games/<名>/shared/` | 该游戏「浏览器 + Node 共用」的内核（只有需要时才建） |
| `games/<名>/server/room.js` | 该游戏的服务端逻辑 |

**隔离是怎么保证的**：

- **消息路由各写各的**：每个游戏的 `room.js` 用 `Hub.routes = { 'xxx.yyy': '方法名' }`
  自己声明能收哪些消息，主机启动时自动装配成路由表 —— 主机里**看不到任何 `tank.*` / `gomoku.*` 字样**。
- **静态资源按前缀挂载**：`games/tank/client/` 挂到 `/tank/`、`games/gomoku/client/` 挂到 `/gomoku/`，
  各游戏的页面、样式、脚本互不引用。
- **自动发现**：主机扫描 `games/` 下带 `server/room.js` 的文件夹并挂载。
  **新增一个游戏 = 新建一个文件夹**，不用改平台层任何代码。
- **主页卡片也自动出现**：主页里只有一个空容器 `#hubGrid`，卡片是脚本按 `/api/status` 渲染的；
  标题、简介、标签、插画全部由游戏自己用 `Hub.title` / `Hub.card` 声明，
  平台层（`platform/`）里找不到任何一个游戏的名字。
- **撞车会被当面指出**：两个游戏注册了同一条消息类型时，主机保留先注册的那个，并在启动日志里打
  `[route conflict]`，同时写进 `/api/status` 的 `routeConflicts` —— 不再像以前那样无声地互相顶掉。
  共用同一个消息前缀、目录名撞上平台保留路径、卡片信息没声明，也都会以 `[game warn]` 列出来。
- **只有需要逐帧推进的游戏才实现 `step/broadcast`**（目前只有坦克），其余游戏主机不会去驱动。

> 想自己（或让 AI / 同学）加一个新游戏？看 **[`games/README.md`](games/README.md)** ——
> 里面有目录/接口约定、最小可运行模板，以及一段**可直接复制的提示词**。

### 联机为什么没延迟

- 该机房内的通信只有一跳：客户端 → 服务器 → 其他客户端，实测 RTT 约 **1ms**。
- 坦克采用**服务端权威模拟 + 客户端本地预测**：你的坦克按下键就动（本机立刻模拟），
  服务端 60Hz 模拟、30Hz 广播快照，客户端把权威位置平滑校正回来，因此「看到的即所按的」。
- 其他玩家与子弹做**快照插值**，画面平滑无抖动；快照体积约 250 字节，30Hz 下约 7.5 KB/s。
- 五子棋是回合制，无任何延迟问题。

## 11. 常见问题

**Q：我加了新游戏 / 改了代码，主页怎么没变化？**
**服务端是在启动那一刻扫描 `games/` 定下游戏清单和卡片的**，所以加游戏、改 `Hub.title`/`Hub.card`、
改关卡文件之后，都要**重启服务端**才会生效（关掉那个「机房小游戏服务器」窗口，重新双击 `启动游戏.bat`），
然后刷新浏览器页面。判断自己连的是不是旧服务端：浏览器打开 `/api/status`，看 `uptime` 和 `games` 列表
—— 如果 `games` 里没有你新加的游戏，就是那个进程还在跑老代码。另外**开着服务端窗口的人**才看得到启动日志，
启动时会打印一行 `已装配 xxx (n 条消息路由)` 和游戏清单，这是最直接的确认方式。

**Q：方块躲避的关卡编辑器在哪？**
编辑器在 `/dodge/editor.html`，有三个入口：① 主页「方块躲避」卡片底部的 **🛠 关卡编辑器** 按钮；
② 游戏内页顶栏的「🛠 关卡编辑器」；③ 主菜单里的「🛠 自己做关卡」。它也支持从内置关卡载入后再改。

**Q：双击 `server\server.js` 弹窗报「语法错误 / 代码 800A03EA / Microsoft JScript 编译错误」？**
那是因为直接双击了 `.js` 文件 —— Windows 会用它自带的脚本宿主（JScript）去执行，
而 JScript 不认识现代 JS 语法（`const` 等），所以在第 5 行就报错了。**这不是游戏出错。**
正确做法：双击根目录的 **`启动游戏.bat`**，或在命令行执行 `node platform\server\server.cjs`。
（`server\server.js` 现在只是一个防误点提示文件，双击它只会弹出一句说明，不会再报错。）

**Q：双击 bat 窗口一闪就没了？**
说明没找到 Node.js。窗口里会提示下载地址；装好 Node 后重新双击即可。
如果确认装了但仍然找不到，可能是安装时没勾选「加入 PATH」，脚本会自动去
`C:\Program Files\nodejs\node.exe` 等常见位置再找一遍。

**Q：其他电脑打不开页面？**
检查三点：① 是否在同一局域网；② Windows 防火墙是否放行（首次启动要选「允许访问」）；
③ 地址是否用了服务器的局域网 IP 而非 `localhost`（启动时控制台会打印可用的局域网地址）。

**Q：房间号输错了？**
会提示「房间号不存在」，重新输入即可。房间号是每次新建房间随机分配的 4 位数。

**Q：方块躲避里我自己做的关卡，别人能玩到吗？怎么改成内置关卡？**
做的关卡默认存在**你这台电脑的浏览器里**（游戏里以「自制关卡」出现，可单人和本地多人玩）。
想让所有人（包括联机）都能玩：在编辑器里「关卡库 → 导出为 .json 文件」，把导出的那一项
追加进服务器上的 `games/dodge/shared/levels.json` 的 `levels` 数组里，重启服务端即可成为内置关卡。

**Q：编辑器里点保存没反应？**
先看左下角的校验提示：**只要有出生点和终点就能保存**（复活点不是必须的：没有的话被撞后就回出生点），
出生点 / 终点不能压在墙上，有问题时保存按钮是灰的。点「🔍 检查能否通关」还能让编辑器算一遍这关到底能不能过。
另外有未保存改动时点「返回主页 / 去玩游戏」会先弹窗问你要不要保存，别以为是没反应。

**Q：好友数据存在哪？服务端重启后会丢吗？**
不丢。好友关系与聊天记录落在服务器上的 `platform/server/friends-data.json`（已加入 `.gitignore`），
重启服务端后自动读回；手动删掉这个文件等于清空所有好友关系，不影响开服。
好友以电脑（IP）为单位，所以同一台电脑重开页面、换游戏，好友都还在。

**Q：五子棋邀请时说「对方已离线」？**
邀请码对应的是**当前在线连接**，对方关掉页面或换电脑后邀请码会变，需要重新让他报一次邀请码。

**Q：五子棋「悔棋」按钮点不动？**
悔棋只在**自己刚下完、对方还没应手**的那一小段时间内可用（按钮会实时点亮，侧栏也会提示「现在可以悔棋」）。
对方一旦应手，这一手就不能悔了；机会不会浪费，等你下一次落子后再悔即可。每人一共只有 1 次机会。

**Q：对局中途关掉网页会怎样？**
坦克对局中离开会立即判负（剩余玩家继续打完剩余局数）；五子棋会通知对手「对方已掉线」。服务器会自动回收房间与对局，不会残留。

**Q：能不能改地图大小 / 单局时限 / 生命数？**
地图大小与单局时限在 `games/tank/shared/tankcore.js` 顶部的常量里（`TILE`、`ROUND_LIMIT`、`RESPAWN_DELAY` 等），
服务端与客户端共用这份文件，改一处即可全局生效。
**生命数不用改代码**：联机房主在房间里直接选 1~5 条（默认 1 条），单机 / 本地双人在开局面板上选。

**Q：想改服务器端口？**
`node platform/server/server.cjs --port 9000`，或设环境变量 `PORT=9000`。
